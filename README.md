# rontenseiri — 論点整理

文字起こし済みの会話を、起点となる議題ごとに振り返るアプリです。時間は左から右へ進み、本筋から派生・ずれが下に伸びます。同じ議題に戻ったときは、別の議題を作らず同じ議題IDを引き継ぎます。

**現在は操作できる設計検証版です。計画書R01–R33の完成版でも、公開条件を満たした正式版でもありません。** 端末内AIの日本語品質・取得条件・実機性能は未検証のため、AI開始は無効です。外部AIで代行した結果や、サンプルを本物の解析結果として表示することはありません。

## 動かす

Node.js 22.12以降（CIは24）を用意します。

```sh
npm ci
npm run dev
```

表示されたローカルURLを開き、「サンプルを見てみる」で架空の会話を確認できます。「新しく始める」ではUTF-8のTXT・MD・SRT・VTTとテキスト貼り付けに対応します。初期状態は未整理です。

## できること

- ノードや議題枠をクリック・タップして選択。空白ドラッグでキャンバス移動、ピンチや＋／−で拡大縮小。
- 枝の折り畳み、隠れた件数表示、全体表示、選択ノードへの復帰、発言ID・本文の検索。
- 図・原文・振り返りで議題ID／発言IDを共有。画面を切り替えてもキャンバスを作り直さず、選択と表示位置を保持。
- 分類・話者・重要印・復帰関係の手動訂正。「復帰先なし」と「未確定」を区別。
- 原文訂正は新しい版として追加し、旧版・変更理由・変更前後を履歴に残す。影響するまとめを要再確認にする。
- 分類変更とは別に、発言の所属先だけの変更、議題の分割／結合、履歴付きUndo。
- 明示保存後はIndexedDBへ自動保存。全体JSONのバックアップと、新しいコピーとしての復元。
- 明示選択した発言だけの限定JSON／Markdown／SVG。未選択・折り畳み・他議題・旧版・履歴・全体のまとめを限定出力に混ぜない。
- スマホ幅では縦向きの振り返りから、次の一手・本筋・派生・ずれ・未決事項・原文に到達。

キーボードはTabで移動、Enterで選択、Escapeで詳細を閉じます。矢印のパンと＋／−のズームはキャンバスにフォーカスがあるときだけ働き、入力欄の操作を奪いません。

## データと通信

アカウントや外部AIのAPIキーは不要です。会話の外部送信、外部検索、共有URLの生成は実装していません。モデル用Worker／交換可能な解析境界はありますが、この版では取得条件・品質評価が完了するまで開始できません。

「この端末に保存」を選ぶまでは一時作業です。保存先は**そのブラウザ・そのオリジン**のIndexedDBで、共有端末からの保護や独自暗号化はありません。サイトデータの消去・容量不足・プレビューURL変更に備えて、全体JSONを控えてください。人物ラベルの仮名化は本文や引用中の名前を消す匿名化ではありません。

入力の上限は10ファイル・合計30MiB・合計50,000コードポイント・5,000発言、個別テキストファイル2MiBです。作業JSON／保存は履歴込み50MiBまでです。大きな入力の快適性を保証する値ではありません。

## テスト

```sh
npm test
npm run build
npm audit
npx playwright install --with-deps chromium
npm run test:e2e
```

既存Chromiumを使う場合は `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/path/to/chromium npm run test:e2e`。E2Eのスクリーンショットと実行結果はローカルの `artifacts/`、失敗時の情報は `test-results/` に出ます。これらはGit管理しません。

## まだできないこと

PDF／DOCX・OCR・音声／動画・URLの取り込み、問い／回答／立場の精密な多対多モデル、不確かな解釈の伝播、差分の再解析、複数タブの推論資源管理は未対応です。スクリーンリーダー、iPhone Safari、Mac／Windows実機、オフライン再起動、品質の固定評価、p95性能、権利・配布・公開オリジン隔離は合格扱いにしていません。

AI実行ができなくても、原文を確かめながら手動で構想と操作を検証できます。**設計検証版の実装完了と、計画書全体の完了・公開承認は別です。**
